# 山猫 IMU 与航向核查

> 以下 10 月 22 日结论仅针对原厂／Airy 内置 IMU，不包括 10 月 26 日新增的十轴 WIT 模块。新模块已按原始协议采样并查询九轴模式，现作为 `rtk_imu` 路径的航向／角速度输入；安装、磁场校准及真北参考仍须现场确认。

日期：2026-10-22。通过 SSH 只读查看驱动、厂商接口说明和 ROS 数据；未发送运动、姿态或校准指令。

## 结论

| 来源 | 已确认的输出 | 航向／磁力计结论 |
| --- | --- | --- |
| Airy 内置 IMU，配置话题 `/airy_201/imu` | 三轴加速度、三轴角速度；加速度为 g，角速度为 rad/s | 当前协议与驱动提供六轴观测，不提供磁场或姿态四元数；不能作为绝对航向源。未取得芯片型号，不能仅据接口断言硬件内部绝无磁力计 |
| 厂商 `/IMU`、`/IMU_103` | 三轴加速度、三轴角速度及四元数，约 190 Hz | 四元数在厂商 DDS 上游已生成；本机转发器不计算姿态。未查到其磁力计、芯片型号及绝对航向参考的证据 |
| `/IMU_DATA` | roll/pitch/yaw、三轴角速度和加速度 | 无磁场字段，无绝对航向参考说明；三个姿态角不等于增加了三个传感器轴 |
| `/FIBOCOM/net_rtk/heading` | 图中有订阅端，当前发布端为零 | 当前不能作为可用航向输入 |

不能把厂商四元数中的 yaw 直接当作北向／ENU 绝对航向。现有证据也不足以断言厂商硬件一定只有六轴。

## 实测

8 秒只读采样：`/IMU` 1522 条，`/IMU_103` 1524 条；frame_id 均为空，全部姿态、角速度及加速度协方差为零（未知）。
1520 对相同时间戳样本的四元数完全相同，最大角速度差约 `4.66e-10 rad/s`，最大加速度差约 `8.98e-7 m/s²`。
这支持同一上游数据经不同转发／精度表示的判断，不能当作两套独立传感器融合；尚未追溯到厂商原始驱动以确认具体链路。
本次未发现名称含 magnetic/compass 或类型为 `sensor_msgs/MagneticField` 的话题；话题缺失不能证明芯片内部没有磁力计。

Airy 驱动源码 `RSAIRYImuPkt` 仅包含三轴加速度、三轴角速度、温度及量程等字段；
`toRosMsg(ImuData)` 只填写这六个测量分量及消息头，没有填写 orientation，默认四元数全零不是有效姿态。
Airy DIFOP 结构另有 yaw／四元数字段，结构字段本身不能证明存在磁力计；当前 IMU 发布路径没有使用它们。

厂商指南只将 `/IMU` 描述为 200 Hz 的通用 IMU 话题，没有给出芯片型号、六／九轴规格、磁北／真北定义或姿态融合算法。
本机 Robonix 包装器只修改 frame_id 和时间戳后转发；它不是厂商姿态解算源。
该包装器 README 对 `/IMU_103` 的“雷达内置 IMU”描述缺乏当前实测支持，不能视为硬件来源证明。

完整 PDF 复核还发现 Body.Yaw、地图位姿查询及初始化 Yaw 接口，但都没有北向定义；
“六轴指令”是控制自由度，不是 IMU 规格。轮关节、速度反馈及文档局限见 [开发指南复核](s10-guide-review.md)。

## 对导航的影响

Airy IMU 可用于激光惯性里程计的短时运动预测。厂商 IMU 的绝对航向在来源确认前保持未验证。
采用“RTK 位置＋绝对航向、雷达只避障”前，仍需要确认厂商航向参考，或验证独立电子罗盘／双天线 GNSS 航向。
即使确认有磁力计，也需要检查装机磁场干扰、标定、安装轴、磁偏角和数据有效性。
