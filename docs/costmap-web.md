# 网页查看导航代价地图

室外启动链路生成了局部／全局代价地图，但没有启动 RViz。
网页现在可直接读取这些地图，不需要 NX 的桌面窗口，也不需要转发 RViz。

## 使用

启动已有导航服务后，仍用原来的隧道和端口：

```bash
# 实机导航
ssh -p 6003 -N -L 8765:127.0.0.1:8765 nvidia@svr.gddg08.top
# 本地浏览器 http://127.0.0.1:8765

# 室内模拟则使用 8766
ssh -p 6003 -N -L 8766:127.0.0.1:8766 nvidia@svr.gddg08.top
```

在 A→B 导航工作区点 **查看实时代价地图**：

- **全局图与局部图同时叠加**，使用紫色／青色区分，可分别开关图层。局部图的空闲及未知区域透明，不遮住全局图。
- 蓝色车标表示山猫位置与朝向；黄线表示当前任务执行路径。
- **鼠标拖动平移、滚轮围绕指针缩放**；拖动后进入自由浏览，点“定位山猫”恢复跟随，点“全图”查看整体。返回路线地图后照常选点导航。
- 顶部和侧栏采用紧凑布局，右侧“路线详情”默认收起，可按需展开。
- 每秒刷新；同时显示坐标系、地图分辨率和数据年龄。超过 3 秒或请求失败时旧图变暗，
  机器人位置变换缺失／过期时不画车标，不会假造一个原点位置。
- 面板是只读的，不会提交目标、清图或发布速度；关闭面板后停止拉取地图。

颜色：浅色=全局空闲，紫色=全局障碍影响区，青色=局部障碍影响区，灰色=全局未知。
浅色只是导航当前的估计，不代表已核实现场安全；灰色也不是“空地”。
模拟档默认关闭障碍层，因此可能没有真实室内障碍显示；这不表示页面未接到地图。

## 实现与接口

- `GET /api/costmaps/local`：`/local_costmap/costmap`，通常为 `odom` 坐标。
- `GET /api/costmaps/global`：`/global_costmap/costmap`，通常为 `map` 坐标。
- 尚未收到地图时返回 503，页面显示等待，不用空白地图冒充真实输入。
- 返回栅格尺寸、分辨率、原点、时间戳、年龄、PNG、机器人位姿和路径，以及 `map_from_frame`（本图坐标到 map 的变换）。
- PNG 按 OccupancyGrid 的 `-1、0..100` 编码取色，不把它当作原始 `0..255` 代价值。
- 图像、机器人和路径统一到 map 坐标叠加；同时考虑地图原点旋转与 Y 轴方向。局部图若缺少新鲜的 map↔odom 变换则不叠加，明确提示未对齐。
- PNG 按地图消息缓存、只在请求时生成，不写磁盘；同一地图消息不因多个页面重复编码。
- 无新增端口、无 rosbridge、无 RViz 桌面转发，也没有修改导航或避障参数。
