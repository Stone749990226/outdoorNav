## 核对方法

保持山猫站稳、不行走。用独立参照测量机头方向：手机指南针应开启真北，
远离机身、电机及其他磁性物体，沿机头方向测量。北为 0°、东 90°、南 180°、西 270°。
手机读数只用于初步核对，需检查其自身精度。

在山猫部署目录执行（工具只读，不发运动指令）：

```bash
.venv/bin/python scripts/check_heading.py --reference-deg 90
```

工具在 5 秒内读取定位服务已完成安装方向和磁北修正的航向，输出真北角度、
短时波动和相对参照的误差。省略 `--reference-deg` 时只采样。
本地源码为 `tools/check_heading.py`，需复制到实机部署的 `scripts/`。

当前朝向完成后，由现场人员通过遥控转向另一个方向、停稳后重复，建议覆盖四个方向。
记录每次参照角度、传感器均值、误差及参照本身精度。若不同方向误差差别很大，
应排查磁场干扰或传感器标定；不要用一个固定偏移强行校正。

短时波动小不等于方向准确。此工具不会自动填写 `quality_confirmed` 或 `yaw_std_deg`；
这些参数须依据独立验证结果确定，不能只取静止样本的标准差。
