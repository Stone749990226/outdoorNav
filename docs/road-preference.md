# 主路优先与路外终点

现场与模拟档启用加权参考路线：道路中心代价 0，向路边连续递增至路外代价（默认 50），允许选择路外终点。
这里的“主路”指现有测绘路网及其配置宽度，不是只指某一条道路。

## 本次改动的边界

- 前端道路权重层中，淡紫色由浅到深表示递增代价，中心线附近最浅，路边与路外同价。
- 路外点击保留原始终点，不再强制吸附到中心线，也不再要求终点距主路 2 m 内。
- 加权模式的起点只要求在规划地图内，不再套用原路网模式的 20 m 救援距离。
- 后台用加权栅格 A* 生成任务参考路线；预览、提交、实际执行共用同一算法。
- **Nav2 全局／局部代价图、雷达转换和避障参数没有修改。** Nav2 仍按实时传感器地图规划每段执行路径；不是把雷达图强行改成道路图。
- 因此，主路偏好作用于任务参考路线，Nav2 局部绕障仍可离开参考线。如果将来要求 Nav2 的每次绕障也直接比较道路权重，需要另加软代价层，不能声称本次已经实现。

## 代价含义

`50` 是业务规划中的软代价值，不是障碍、不是“50% 有障碍”，也没有写入 Nav2 传感器图。
软代价采用 `C × min(d / (w/2), 1)`：`C` 为路外代价，`d` 为到道路折线的距离，`w` 为既有道路宽度；重叠道路取较低代价。没有新增路边阈值或独立调节参数。栅格保存浮点代价，公式在路边连续，显示仍受栅格采样分辨率限制。封路／参考禁行区仍为硬约束，不参与软代价渐变。
路径长度仍参与计算：中心线代价 0 并不是零距离、无限绕路也没有代价。
默认 `C=50` 时，路外每米约为中心线每米的三倍；道路内部在两者间连续变化。优先借主路接近目的地，然后离开主路到达目标；
当绕主路过远时，也允许选择合理的路外连接。

**可规划不代表已确认安全。** 示意建筑、PGM 非主路色块不是现场验收过的障碍数据，不自动变成实机硬禁区。
真实障碍仍由现有雷达代价图拦截；坑洞、台阶等感知缺口并没有因为加权规划得到解决。

## 配置

`deploy/lynx/robot.fieldtest.json` 与 `robot.mock.json`：

```json
{
  "road_preference_enabled": true,
  "road_offroad_cost": 50,
  "road_preference_resolution_m": 0.5,
  "road_keepout_polygons": []
}
```

- `road_offroad_cost` 可设 1～99；越大越不愿走路外。参考规划分辨率 0.5 m，不影响原有传感器代价图分辨率。
- 关闭 `road_preference_enabled` 后保留原路网模式，兼容原来的巡航／仿真流程。
- 地图外的目标仍拒绝，不支持无限范围导航。
- 封闭道路在**参考规划**中保持禁止；`road_keepout_polygons` 是可选的参考规划禁行多边形，格式为米制 map 坐标的 `[x,y]` 顶点数组。
- 这些业务规划约束没有成为 Nav2 的硬禁行层，不能代替需要安全保证的禁行区域。若要在所有绕障动作中强制禁止穿越，应接入专用 Nav2 禁行层。

## 页面与接口

连接启用了该策略的导航服务后，路线地图出现“显示／隐藏道路权重”按钮，可在地图范围内选路外终点。
左侧“路外代价”滑条可调 1～99，权重图随即更新；调整后点“规划 A→B”重新比较路线。调大更偏向路中与主路，调小更偏向短路径，不保证所有起终点都会出现不同路线。
仍然先规划、再执行；改变滑条会使旧预览失效，必须重新规划后才能执行。数值随预览与任务请求发送，并固定在该任务中；拖动滑条不会改变正在执行的任务或其他页面的默认值。服务未提供当前位置时不能规划。
未连接服务或使用旧路网策略时，保留原先离线路网预览，不伪造一条已由后台验证的路外路线。

`/api/status` 的 `planning_policy` 返回策略、主路／路外代价和地图边界。
`/api/plans` 返回实际起点、原始终点、参考路线、长度和加权成本；后端不替换成最近主路终点。

## 只看网页效果，不连接实机

已构建前端时，在仓库根目录运行：

```bash
python3 -m tools.road_preview --port 8877
```

需要 Python 与 NumPy，不需要 ROS、RTK、IMU、雷达或实机。打开 `http://127.0.0.1:8877/`，
进入“A→B 规划”，A 是固定模拟起点；在主路外点击 B，然后点“规划 A→B”。
淡紫区域是路外软权重，预览调用真实加权规划器；可切换显示道路网络，查看参考路线是否优先沿主路。
执行导航始终禁用，服务端也拒绝任务执行。页面显示“未就绪”是正常的，原因栏会注明仅规划预览。
需要换模拟起点时加 `--start X Y`（map 米制坐标）。服务为前台常驻，按 Ctrl+C 退出。

本机使用已有测试容器时也可运行 `docker exec -it -w /work outdoornav-main python3 -m tools.road_preview --port 8877`；
该容器使用宿主网络，浏览器仍访问相同地址。仅适用于当前本机容器，不是山猫上的启动命令。
