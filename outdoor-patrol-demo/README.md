# 智慧谷北区实测路线工作台

当前路网来自 `1.ubx` 的环线与 `2.ubx` 的中央支路。两份日志均为差分解质量 `2`，绝对位置精度未独立验证。网页叠加依据高德地图与卫星参考图绘制的园区示意底图，表现中央 30 层主楼、东侧裙楼、屋顶花园和绿地。

底图源文件为 `src/assets/north-building-basemap.svg`，按当前实测地图的 976 × 952 显示坐标绘制，建筑、道路宽度和阴影仅作视觉示意，不参与选点、规划、导出或 Nav2 障碍物判断。巡航页可在图层设置中关闭，A→B 页可通过“显示园区底图”按钮切换。重新采集或改变地图显示原点、比例后，需要重新调整底图位置。

## 运行

Node.js 22.12 或更新版本：

```bash
npm ci
npm run dev
```

应用不请求在线地图或字体。网页可独立规划及预览；ROS2 桥接未连接时发送按钮不可用。

## 路线与交互

- A→B：点击路线附近设置 A/B，页面显示投影后的中心线位置。容差为 12 屏幕像素，随缩放保持一致；它不表示道路宽度。
- 规划：按实测折线长度在双向路网上运行 A*，环线优先选择较短方向。起终点可位于任意线段中间，不限于三个固定节点。
- 封路：关闭一段环线可从另一段绕行；关闭支路后其内部目标不可达。封路会使 A/B 的旧规划与导出失效，保留投影点，重新规划时不改换目标。
- 巡航：默认环线起点 → 公共路口 → 支路端点 → 返回起点，每个巡检点停留 2 秒。保留增删任务、排序、暂停、倍速及封路重规划，取消旧地图的自动封路脚本。
- 对比：A/B 地图的“原始 / 滤波”开关显示原始测量与滤波轨迹；最终路网保留独立的闭环、接入口修正。
- 显示：米制网格、北向、比例尺、缩放、平移和道路连接。参考图片可手动导入作显示层，不改变导航坐标。

## 坐标与生成

在仓库根目录运行：

```bash
conda run -n torch python tools/build_survey_map.py
```

生成器使用原点文件中的共同原点，X 向东、Y 向北，单位米。首次原点来自环线末尾稳定停留段的经纬度中位数。SVG 仅使用比例与 Y 轴翻转显示，0.125 米/图形单位；不再通过旧手绘图的 N/E 地标拟合。

处理顺序为时间检查、Hampel 孤立跳点检测、停留压缩、保留转角的短窗口平滑、0.5 米重采样及 0.15 米容差简化。超过 2 秒的缺测或异常连续跳变保留为断段，当前两段重建任务遇到断段会失败，不自动补线。

闭环接缝最多修正 2 米，用户确认的支路接入口最多修正 5 米；均只调整局部并记录报告。当前环线约 345 米、支路约 36 米。

结构化米制原始点、滤波点、最终路网和 SVG 位于 `../survey/north_building/`。`src/campus.json` 是派生显示坐标；地图及路径 JSON 导出的是米制坐标。

## Nav2

仓库根目录执行 `bash ros2_bridge/run_sim.sh`，启动 Map Server、Regulated Pure Pursuit 控制器、仿真机器人及 HTTP 桥接。

网页“发送仿真路径”将完整 `nav_msgs/Path` 发送给 `FollowPath`；桥接按约 0.25 米加密，发布重要点，并反馈里程计、剩余距离和结果。零长度 A/B 在网页直接完成，不发送给 Nav2。

桥接严格校验当前地图版本、配准状态、坐标原点和有限数值。网页检测到旧版本时禁用发送且不叠加旧地图位置。更新地图后重新运行启动脚本，重新安装生成物并重启节点。

`campus_sim.pgm` 为路网外加至少 10 米余量的无障碍仿真区域，分辨率 0.2 米；它不用于证明道路边界或自由空间。当前仿真配置关闭碰撞检测。实机仍需要与此地图一致的定位、机器人尺寸、传感器代价地图和控制接口。

## 导出

地图 JSON 包含 `centerline_graph`、三个节点、两段环线、一条支路及各段日志来源。路线 JSON 包含投影后的 A/B、完整米制路径、关键点及地图版本；CSV 包含坐标、参考朝向、累计距离和入选原因。

`frame_id: map`，`scale_is_mock: false`，`calibration_status: survey_dgps_unverified`，`executable_on_robot: false`。附带经纬度是规划坐标反算值；实测尺度不代表绝对精度已验证。

重要点保留起终点、实际路口、转角、最多 20 米间隔及必要的形状点。完整路径始终一同输出，稀疏重要点不替代路径几何。

## 验证

```bash
npm test
npm run build
npx playwright install chromium
npm run test:e2e
BRIDGE_REAL=1 npm run test:e2e
```

最后一条需要已经启动 Nav2。已有 Chromium 时可用 `PLAYWRIGHT_EXECUTABLE_PATH=/path/to/chrome`；指定网页端口用 `PLAYWRIGHT_PORT`。截图保存在 `test-results/`。

`npm run test:e2e:firefox` 是可选的系统 Firefox / geckodriver 验收，要求可执行文件已安装；可通过 `FIREFOX_BINARY`、`GECKODRIVER_BINARY` 指定路径。
