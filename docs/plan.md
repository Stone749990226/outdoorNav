# 山猫室外导航实施状态

目标：网页／Robonix 选道路附近目标 → 路网选路 → Nav2 分段规划与雷达绕障 → 到达停车。

## 架构

- 仿真和山猫共用目标校验、路网引导、任务管理与路线执行器。
- 实机使用 NavFn、DWB、速度平滑和独立看门狗；不运行室内 RTAB-Map／ICP 和原单点导航包装服务。
- 不使用 `/ODOM` 或外部连续里程计。当前默认以原 RTK 位置／多普勒速度和新十轴 IMU 航向／角速度生成导航反馈；安装、真北参考、反馈质量及运动确认仍保持关闭。
- 室外动态 TF 使用 `/outdoor/tf`，共享静态传感器外参；不消费厂商公共动态 TF。
- 室内静止诊断使用独立速度话题并拒绝导航，不修改原始标定值或启动第二个 GNSS 读取者。
- 网页和 Robonix 共用同一 HTTP 后端及任务所有者；山猫直接托管网页。
- 室内外使用不同 manifest，互斥启动；删除旧的单点转发和 GNSS-only 里程计生产路径。

## 已实现

- 道路附近 2 米内选点投影、已确认地点、人工封路、真实参考路线预览。
- 连续路线执行、路径反馈、请求去重、取消和替换、重启不恢复运动。
- 固定／浮点解统一质量门槛，任务验收档位持久化，固定解任务不自动降级。
- 保留原始里程计时间、计算运动速度、断流停车、TF 和命令发布冲突检查。
- 同源网页托管、室外 manifest 生成器、完整构建／启动入口及只读传感器检查工具。

## 默认参数

统一定义于 `outdoornav/config.py`，机器人实测配置覆盖默认值：

| 参数 | 固定解 | 浮点解 |
| --- | --- | --- |
| 最大报告 hAcc | 0.20 m | 1.0 m |
| 到达位置容差 | 0.5 m | 1.5 m |

连续稳定 5 秒；GGA 改正年龄不超过 5 秒；传感器超过 1 秒无更新停止；命令超时 0.3 秒。
线速度不超过 0.15 m/s，角速度不超过 0.4 rad/s。默认关闭运动，现场确认项默认 false。

## 验收顺序

1. 源码、核心测试、网页构建及浏览器回归。
2. 山猫临时目录 ROS 构建、隔离 ROS 域零输出联调、原始传感器只读检查。
3. 现场确认新 IMU 安装外参、磁偏角与航向精度、原 RTK 天线杆臂和地图原点，核查隔离 TF 及传感器静态外参，核对雷达覆盖及安装偏移。
4. 短距离到达、取消停车，再验证多弯路线、静态／动态障碍及持续堵路。
5. 使用正式室外 manifest 验证 Service、网页和重启行为。

现场运动验收由现场人员执行。不得用测试通过、报告 hAcc 或算法成功代替独立测量的到达误差和停车证据。
当前验证记录见 [山猫验证记录](lynx-validation.md)，操作入口见 [部署说明](../deploy/lynx/README.md)。
