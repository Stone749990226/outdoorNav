| 范围 | main | 新分支 |
| --- | --- | --- |
| 障碍输入 | 雷达投影与感知代价图为主 | 雷达、RGB-D 可单独或同时启用，各有独立图层；相机增加时序稳定性过滤，并保留原负障碍检测链。 |

## 本轮架构修复（不靠继续放大阈值）

1. **底盘准备和速度放行分开。** 控制/使用模式、反馈和步态输出许可满足后，可从常规步态请求导航步态；速度必须等真实步态确认。不再用 require_chassis_ready=false 破除循环等待。
2. **规划模式不抢步态管理。** 普通/周期规划、terrain 开/关四种组合都走明确的准备流程；仅平地监督时也会请求并确认导航步态。开启周期规划不再强制开启 terrain。
3. **接收积压与观测配对分开。** 保留 main 的独立 TF 接收线程；周期规划从有界队列取采集时刻 TF 已齐的最新帧，而不是延长阻塞等待或改写源时间戳。
4. **时间预算按职责归属。** 定位状态/位姿/速度共用 localization_timeout_s；障碍时效、最终命令看门狗仍独立。任务恢复时间不重复算进规划 RPC 等待时间，准备与步态确认也不再混成一个计时器。
5. **保留有序路线进度。** 步态与规划共用进入下一相邻路段的几何判定，避免绕弯后一个模块已前进、另一个仍卡在上个顶点；定位修正后重规划不返回原始起点。
6. **故障可诊断、可安全恢复。** 定位回放出错原子回退，明确撤销有效估计并重新初始化，不静默滑行；定位修正/重置要释放旧控制目标。输出竞争消失时丢弃旧速度，不自动重启终止任务。
7. **地图只由一处配置。** 删除现场的 global_grid 覆盖和猜测性分辨率补丁。短规划窗口/周期快照可沿长路线推进，不要求最终目标一直在当前感知窗口内。无路径时报告实际失败点和 action 结果。

必要的安全边界、物理标定、速度/足迹与模型置信度没有取消；目标是消除重复和循环依赖，不是“零阈值”或忽略失效输入。

## 当前默认部署与未完成项

- 实机配置为 lidar-only，Orbbec RGB/深度预览保留；RGB-D 几何后端可显式选择 legacy 或 RTAB-Map。
- terrain 和周期规划可同时开启，但 `can_climb_stairs=false`，本轮只验证平地。实时楼梯识别仍需模型/语义源和独立实机验证；不是已经完成纯雷达识别楼梯。
- 相机安装位置仍是可配置参数，当前粗略参数未等同于完整外参标定。
- 室内使用模拟传感器和底盘，没有启动真实运动命令。模拟不证明真实磁航向、户外深度有效性、避障安全距离或楼梯通过能力。
